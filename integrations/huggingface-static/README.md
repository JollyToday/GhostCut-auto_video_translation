# Weydub Pro Subtitle Removal

Choose an H.264 MP4 (up to 16 MiB and 60 seconds), confirm permission and submit it. Pro checks the full frame, so it can also remove signs or prices. The Weydub media lab hosted on Hugging Face forwards the file to Weydub for processing. Keep the private receipt to check progress or retrieve the cleaned MP4 after reopening the page. Status checks never start another job. Anonymous integrations together share 100 sponsored clips per UTC month; the trial does not start a paid job.

Use the [Weydub editor](https://weydub.com/subtitle-removal/) for selected regions, longer clips and batches. The [media lab](https://huggingface.co/spaces/iniu/weydub-media-localization) remains available for past trials, OCR, dubbing and image translation. For account-based use see the [developer guide](https://weydub.com/docs/api/).

The licensed sample shows captions moving **between cuts**: [source and usage details](https://github.com/JollyToday/GhostCut-auto_video_translation/tree/c4d72c4/examples/full-frame-removal). The two MP4 links in the app are the actual input and delivered Pro result. The Space runs no server and contains no account credentials.
